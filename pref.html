Engine引擎

Speech recognition engine语音识别引擎

whisper.cpp is the default and is packaged by Homebrew as brew install whisper.cpp. mlx-whisper uses the Apple Neural Engine. Custom command runs any local tool that turns a WAV file into an SRT file. whisper.cpp 是默认引擎，Homebrew 用 brew install whisper.cpp 安装。mlx-whisper 使用 Apple 神经网络引擎。 自定义命令可运行任何能把 WAV 文件转成 SRT 文件的本地工具。

Used by the whisper.cpp engine.whisper.cpp 引擎使用该路径。

Path to the mlx-whisper executable, or the full command line for the custom engine. Placeholders: {input} {audio} {output} {model} {language} {start} {duration}. mlx-whisper 可执行文件的路径，或自定义引擎的完整命令行。 可用占位符：{input} {audio} {output} {model} {language} {start} {duration}。

Model模型

Path to a ggml model file, for example ~/iina-asr/models/ggml-large-v3-q5_0.bin. The button in the sidebar tab of the plugin fetches one. ggml 模型文件的路径，例如 ~/iina-asr/models/ggml-large-v3-q5_0.bin。也可以在插件的侧边栏中一键下载。

Optional. For example http://127.0.0.1:7890. It is used when a model is fetched, and for nothing else. 可留空。例如 http://127.0.0.1:7890。仅在下载模型时使用。

Audio音频

The audio is decoded with the media framework that macOS ships with, so no external decoder is needed.音频使用 macOS 自带的媒体框架解码，无需任何外部程序。

ISO code such as zh, en, ja, or auto to detect it. English only models (.en) ignore this setting. ISO 代码，例如 zh、en、ja， 或用 auto 自动检测。仅支持英文的模型（.en）会忽略此项。

The script of the Chinese subtitles中文字幕的字形

The model writes Chinese in whichever script it thinks it heard, and it may change the script in the middle of a file. Here the model is told which script to write in, and what it wrote anyway is brought into that script afterwards. The setting is only used for Chinese. 模型会按自己听到的字形来写中文，甚至在同一支片子里混着写。 这里会先告诉模型用哪种字形写，模型写完后再统一成这种字形。此项只对中文有效。

Chunking分段

The file is transcribed in chunks of this length so that subtitles appear while the video is still playing. Longer chunks give the model more context. 文件按此长度分段转写，因此播放过程中就能看到字幕。分段越长，模型能获得的上下文越多。

Extra audio decoded after every chunk so the model hears the end of a sentence. Cues that start inside the overlap are dropped. 每段之后额外解码一段音频，让模型能听到句子的结尾。起始于重叠区的字幕会被丢弃。

Behaviour行为

Subtitles then appear on their own, without touching the menu. A file that has already been transcribed is loaded from the cache straight away. 字幕会自动出现，无需操作菜单。已经转写过的文件会直接从缓存载入。

The transcript is kept in the plugin folder. Nothing is written next to the video unless the export command is used. 字幕保存在插件目录中。除非使用导出命令，视频旁边不会写入任何文件。
