iina-sub Settings

Engine

whisper.cpp is the default and is packaged by Homebrew as brew install whisper.cpp. mlx-whisper uses the Apple Neural Engine. Custom command runs any local tool that turns a WAV file into an SRT file.

Used by the whisper.cpp engine.

Path to the mlx-whisper executable, or the full command line for the custom engine. Placeholders: {input} {output} {model} {language}.

Model

Path to a ggml model file, for example ~/iina-asr/models/ggml-large-v3-q5_0.bin. Use Plugins → iina-sub → Download Recommended Model to fetch one.

Audio

The audio is decoded with the media framework that macOS ships with, so no external decoder is needed.

ISO code such as zh, en, ja, or auto to detect it. English only models (.en) ignore this setting.

Chunking

The file is transcribed in chunks of this length so that subtitles appear while the video is still playing. Longer chunks give the model more context.

Extra audio decoded after every chunk so the model hears the end of a sentence. Cues that start inside the overlap are dropped.

Behaviour

Subtitles then appear on their own, without touching the menu. A file that has already been transcribed is loaded from the cache straight away.

The transcript is kept in the plugin folder. Nothing is written next to the video unless the export command is used.
